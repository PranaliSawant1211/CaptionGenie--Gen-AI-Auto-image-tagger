# 📸 Caption Genie: Gen AI Auto Image Tagger

**Caption Genie** is a Streamlit-based web application that enables users to generate real-time image captions and hashtags using Google’s Generative AI. Built for content creators, marketers, and AI enthusiasts, it provides an intuitive interface for effortless image understanding and description.

🔗 **Try it Live**: [https://image-caption-tagger.streamlit.app/](https://image-caption-tagger.streamlit.app/)

---

## ✨ Features

- **🖼️ Image Upload**: Upload JPG, PNG, or JPEG files.
- **🧠 GenAI-Powered Captioning**: Automatically generate descriptive captions using Google’s Generative AI.
- **🏷️ Tag Extraction**: Extract relevant hashtags for your image.
- **🛡️ API Key Validation**: Prompts user for Google API key and handles errors gracefully.
- **📊 Visual Results**: Displays uploaded image, generated caption, and hashtags in a clean layout.
